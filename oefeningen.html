Hoe voer je ze uit

De 46 oefeningen uit je Garmin-script, in gewoon Nederlands. Op je epix zie je van elke oefening ook een animatie: blader vóór het starten door de stappen en druk op START.

Niets gevonden. Probeer een deel van de naam.

Namen staan in het Engels omdat je horloge ze zo toont. De code tussen haakjes is de sleutel die het script naar Garmin stuurt.
